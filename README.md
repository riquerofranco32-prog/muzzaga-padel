# Muzzaga Pádel

Landing page del club de pádel Muzzaga (Catriel, Río Negro).

Sitio estático (`index.html`), sin build step — deploy directo en Vercel.

## Editar contenido

Todo el contenido (precios, menú, WhatsApp, Instagram) está en `index.html`. Es HTML plano con estilos inline; no requiere `npm install` ni build.

## Deploy

Importado en Vercel desde este repo. Cualquier push a `main` dispara un deploy automático.
